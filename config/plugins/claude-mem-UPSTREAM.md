# claude-mem OpenCode bundle

`claude-mem.js` was generated by the official installer from
`thedotmack/claude-mem` version `13.12.4`.

Source commit audited during installation:
`132b46343e60ecf4057c427736c57b08f7615dfe`.

The official bundle captures OpenCode tool/chat events and exposes
`claude_mem_search`. `claude-mem-autostart.mjs` is the user-global companion
that starts the worker and injects current project memory.
