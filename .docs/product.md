# Product

Documentation status: `verified`

Last verified: 2026-07-27

## Audience and problem

Developers who want a small reproducible OpenCode setup backed only by GitHub
Copilot.

## Outcomes

One direct model provider, project-local code intelligence, and no auxiliary
gateway or conversational-memory service.

## Primary workflow

Clone, add the private Copilot token, install, and start OpenCode.

## Non-goals

Multi-provider routing, prompt rewriting, and cross-session conversational
memory.
